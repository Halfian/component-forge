# Component-Forge

    This project started as an idea for a drag-and-drop playground. By expirementing with layouts, state management, and styling, the goal was to create a simple scalable environment for building and testing UI components.

    With Component Forge, you can:
    - Play around with a drag-and-drop canvas
    - Style components interactively using the Inspector section
    - Track and render components via a dynamic tree structure
    - See instant updates with live preview

    This project is about having fun while building. It’s a space to experiment with component design, drag‑and‑drop interactions, and scalable architecture.

# Tech Stack

    - React + vite for it's fast setup
    - TailwindCSS v4 for styling with responsive design
    - Zustand for lightweight state management
